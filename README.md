# OWNPACE® — DROP 001 / Preview

**WEAR YOUR PACE.** Демонстраційний сайт концепції українського бренду одягу.

## Що вже працює
- Три окремі дизайн-напрями: **NOIR (01)**, **ATELIER (02)** та **TERRAIN (03)**.
- Каталог із **12 візуальних концептів** одягу: зипки, baggy-штани, bootcut і baggy-джинси, куртки, футболки.
- Фільтри за колекцією і типом, пошук, детальний перегляд і обране (зберігається лише у браузері).
- Адаптивне меню для телефонів.
- Концепти трьох видів фірмового пакування.

## Важливо
Це **демо, не магазин**. Замовлення, оплата, облікові записи і збір електронних адрес вимкнені.
Фото в оформленні — ілюстративні редакційні зображення; вироби і пакування — концепти. Реальні зразки, матеріали, ціни, сертифікація й строки не підтверджені.
Зовнішні фотографії завантажуються з Unsplash, шрифти — з Google Fonts, тому потрібне інтернет-з'єднання.

## Як подивитися локально
Відкрийте `index.html` у браузері. Усі файли мають бути в одній папці: `index.html`, `style.css`, `script.js`, `favicon.svg`.

## Як опублікувати в GitHub Pages
Repository **Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save**.
Після успішного розгортання сайт буде за адресою `https://mankinka134.github.io/ownpace-website/`.

## Наступний етап
Затвердити один базовий логотип і додаткові знаки для ліній; додати власні фото/3D, перевірити матеріали та виготовити пробні вироби. До початку реальних продажів узгодити відповідні юридичні та платіжні вимоги.
