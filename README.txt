OWNPACE — DROP 001 — версия 3.0 (полноценное локальное демо)

КАК ОТКРЫТЬ
  1. Распакуйте ZIP в папку.
  2. Дважды нажмите index.html.
  3. Сайт откроется в браузере без сервера. Для шрифтов из Google Fonts нужен интернет, но фотографии лежат внутри папки assets.

КАК ОБНОВИТЬ ПУБЛИЧНЫЙ САЙТ
  Откройте https://github.com/mankinka134/ownpace-website/upload/main
  Перетащите ВСЕ файлы И папку assets из распакованной папки (не сам ZIP).
  Нажмите Commit changes. GitHub Pages опубликует новую версию через несколько минут.
  Файлы старой версии остаются в репозитории, но index.html теперь подключает main.css и app.js.

ЧТО ВНУТРИ
  - Три самостоятельных страницы NOIR, ATELIER и TERRAIN.
  - 16 концептов одежды и аксессуаров, включая серый вязаный джемпер из пользовательского референса.
  - Реальные изображения из выбранных макетов (кропы) вместо стоковых фотографий и CSS-рисунков.
  - Три упаковки, детали, лукбук, общий каталог, поиск, избранное, адаптивная версия.
  - Нет кнопки оплаты и сбора e-mail.

ВАЖНО
  Это дизайн-концепт, а не фото готовых товаров. Некоторые картинки извлечены из общих мокапов и поэтому имеют ограниченную детализацию.
  Фото серого джемпера является присланным пользователем референсом; права на коммерческое использование этого фото не подтверждены — перед реальным коммерческим запуском заменить собственным снимком.
